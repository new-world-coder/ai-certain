# AI-CERTAIN Roadmap (2026–2031)

The roadmap is **conditional**—progression follows real incidents, regulation, and AI capability rather than fixed predictions.

## Open-source phases

| Phase | Deliverable |
|-------|-------------|
| **1** | Threat model, architecture, protocol drafts, governance (this release) |
| **2** | Reference **AICP gateway** — identity, manifests, policy evaluation, signed evidence |
| **3** | HTTP gateway, network enforcement, DNS integration |
| **4** | Local sandbox, quarantine, emergency revocation demonstrator |
| **5** | AISIG specification, public test corpus, attack scenarios |
| **6** | Federated threat signals between independent nodes |
| **7** | Router / edge implementations |
| **8** | **AI-CERTAIN Grid** — opt-in distributed research compute |

**Flagship demo:** an agent with deliberately excessive privileges; external control plane observes ? detects ? constrains ? revokes ? quarantines ? recovers **without agent cooperation**.

## Calendar milestones

- **2026–2027:** specification, threat model, reference gateway, sandbox, evidence schema, test suite
- **2027–2028:** network adapters, identity integrations, AISIG registry, federated exchange, security audits
- **2028–2029:** edge implementations, enterprise integrations, critical-infrastructure pilots, formal verification (selected controls)
- **2029–2030:** large-scale federation, academic grid, interoperability pilots, standards-body engagement
- **2030–2031:** multiple vendors, public-interest nodes, mature ecosystem
