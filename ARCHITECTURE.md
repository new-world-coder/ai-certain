## Layer summaries

| Layer | Responsibility |
|-------|----------------|
| 1 | Accelerator scheduling, resource quotas, hardware isolation |
| 2 | OS identity, sandboxing, filesystem boundaries, credential isolation |
| 3 | DNS policy, routing, egress filtering, network quarantine |
| 4 | HTTP/API gateways, AI provenance metadata, DLP, indexing policy |
| 5 | Evaluate agent requests, tool calls, high-impact actions |
| 6 | Agent identity, capability manifests, delegation, emergency revocation |
| 7 | Continuous evidence, anomaly detection, incident response, human override |

## Core primitive: AI capability firewall

Evaluates **actions**, not model “goodness.” Decisions: `ALLOW`, `DENY`, `STEP-UP`, `QUARANTINE`.

Inputs may include agent identity, declared purpose, capability, target, data class, transaction value, reversibility, authority, environment, reputation, and threat signals.

## Deployment tiers

- **Individual** — desktop/browser gateway, local sandbox, provenance inspection
- **Enterprise** — API gateway, registry, evidence store, SIEM integration
- **Critical infrastructure** — segmented AI zones, high-impact approval, independent emergency controls
- **Router / edge** — DNS, egress policy, device isolation
- **Cloud** — workload identity, scheduler integration, accelerator quotas
