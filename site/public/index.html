White Paper v0.1 · October 2026

AI-CERTAIN

A global open infrastructure for AI containment, resilience and democratic control. Proposed by Sachin Chitre / RiskLine ecosystem.

No AI system should ever possess more power than an independent, auditable control layer can revoke.
Download PDF About this release

What this publication is

  • Canonical Phase 1 release of the AI-CERTAIN open infrastructure proposal
  • Threat model, seven-layer architecture, and draft protocol family (AICP, AEP, ACP, AISIG, AIRP, AIRM)
  • Vendor-neutral: open protocols first; RiskLine is positioned as continuous assurance—not the owner of the control plane
  • Source of truth is intended to live in a public ai-certain GitHub repository (Markdown specs + this PDF)

Publication channels (from planning thread)

  • Primary: public GitHub repository ai-certain
  • Engage (not one-click publish): OWASP GenAI, NIST/NCCoE discussion, C2PA for provenance
  • Later: arXiv / ACM / IEEE after implementation and evaluation; IETF for protocol drafts
  • Distribution: RiskLine and LinkedIn announce and link—do not treat as ownership
