# Security

## Reporting vulnerabilities

If you discover a security issue in a reference implementation (Phase 2 onward), please report it responsibly.

**Until a dedicated security contact is published:** open a **private** security advisory on the canonical GitHub repository, or email the maintainers listed in the repository profile once configured.

Please include:

- Description and impact
- Steps to reproduce
- Affected component / commit
- Suggested fix (if any)

## Scope

- Reference gateway, firewall adapters, runtime sandbox, and federation components
- Not in scope: third-party models, cloud provider platforms, or deployments you do not operate

## Disclosure

We aim to acknowledge reports within 7 days and coordinate disclosure timelines with reporters.
