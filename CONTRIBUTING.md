# Contributing to AI-CERTAIN

Thank you for helping build open AI containment infrastructure.

## How to contribute

1. Read [WHITEPAPER.md](./WHITEPAPER.md), [THREAT-MODEL.md](./THREAT-MODEL.md), and [ARCHITECTURE.md](./ARCHITECTURE.md).
2. Open an issue for substantial design changes before large pull requests.
3. Keep protocol changes in [PROTOCOLS/](./PROTOCOLS/) with clear versioning.
4. Prefer evidence-based threat descriptions; avoid political scoring in threat intel formats.

## Code of conduct

Participation is expected to be professional, inclusive, and focused on deployable security properties.

## Technical bar (Phase 2+)

Reference implementations should document measurable properties: policy latency, revocation time, evidence completeness, and false-positive behaviour under defined testbed scenarios in `testbed/`.

## Questions

Use GitHub Discussions once enabled on the canonical repository, or issues for specification clarifications.
